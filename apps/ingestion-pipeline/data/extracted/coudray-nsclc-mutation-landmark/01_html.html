Coudray NSCLC Mutation Landmark is a standalone literature project created from the reference layer of the supplied gene-mutation paper so that the MemoryTonic collection can contain multiple comparable projects instead of only one synthesized overview. The practical purpose of this project is to create graph structure that supports bridges, cross-paper comparison, and clearer separation between evidence types. In the original uploaded collection there was only a single project, which meant there could be no bridge entities by definition even if the research itself was thoughtful. This project addresses that structural limitation by representing one coherent slice of the cited literature as its own graph-ready unit. The focus here is: A project built from the anchor paper's description of the 2018 Coudray study that established early proof that non-small cell lung cancer histopathology could support mutation prediction for driver genes such as EGFR and KRAS. The project therefore captures the entities, methods, validation themes, and clinically relevant concepts that recur in this part of the literature, especially histopathology images, mutation prediction, precision oncology, and the conditions under which claims should be trusted. It also encodes the difference between promising internal results and stronger external evidence. By storing this literature slice as a separate project in the same Gene Mutation Research collection, the graph can now discover which concepts are repeated across projects and which themes are unique to a single paper or subfield. That is what makes bridge entities meaningful in this platform: not a single long paper, but several connected projects that share important vocabulary, methods, datasets, and limitations.
